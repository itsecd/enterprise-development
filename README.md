# Лабораторная работа 1 
## Служба доставки еды (FoodDelivery)

Лабораторная работа по разработке предметной области и модульных тестов.

## Описание предметной области

В базе данных службы доставки еды хранятся сведения о ресторанах, блюдах, клиентах, курьерах и заказах:
* **Блюдо (`Dish`)**: характеризуется названием, весом в граммах (`Weight`), ценой (`Price`). Категория блюда является отдельным справочником (`DishCategory`). Блюдо связано с рестораном (`Restaurant`).
* **Категория блюда (`DishCategory`)**: справочник категорий (например: «Пицца», «Суши», «Бургеры», «Салаты»).
* **Ресторан (`Restaurant`)**: содержит сведения о названии, адресе, рейтинге (`Rating`), часах работы (`WorkingHours`), а также списки блюд меню и оформленных заказов.
* **Клиент (`Customer`)**: характеризуется ФИО (`FullName`), номером телефона (`PhoneNumber`), адресом доставки (`DeliveryAddress` / `Address`), а также историей заказов.
* **Заказ (`Order`)**: содержит информацию о клиенте, ресторане, назначенном курьере, времени оформления (`CreatedAt`), времени доставки (`DeliveredAt`), адресе доставки, статусе, способе оплаты, стоимости доставки (`DeliveryFee`), итоговой сумме (`Total`) и позициях заказа (`Items`). **Используется в качестве контракта.**
* **Позиция заказа (`OrderItem`)**: строка заказа, реализующая отношение «многие-ко-многим» между заказом и блюдами. Содержит ссылку на заказ (`OrderId`), блюдо (`DishId`), заказанное количество (`Quantity`) и цену за единицу на момент оформления (`UnitPrice`).
* **Курьер (`Courier`)**: характеризуется ФИО, номером телефона, способом передвижения (`TransportType`).
