# Лабораторные работы №2 и №3

## Предметная область: Гостиница

## Описание
В рамках лабораторных работ реализовано серверное приложение на ASP.NET Core (.NET 10), предоставляющее REST API для управления гостиницей. Приложение поддерживает базовые CRUD-операции, а также предоставляет результаты аналитических запросов.

Хранение данных реализовано с использованием MySQL и Entity Framework Core. Для управления структурой БД используются миграции. Оркестрация всех компонентов приложения (API, база данных, сервис миграций) выполняется с помощью **.NET Aspire**.

## Стек технологий
*   **Платформа:** .NET 10, ASP.NET Core Web API
*   **ORM:** Entity Framework Core (провайдер Microting для MySQL)
*   **База данных:** MySQL
*   **Оркестрация:** .NET Aspire
*   **Тестирование:** xUnit
*   **Документация API:** Swagger / OpenAPI

## Сущности
*   `Client` — клиент гостиницы
*   `RoomType` — тип номера (категория, вместимость, цена)
*   `Room` — номер (этаж, наличие балкона, тип)
*   `Booking` — бронирование (клиент, номер, даты заезда и количество суток)

## Архитектура проекта
Проект реализован с разделением на слои (Clean Architecture):
*   `Hotel.Domain` — сущности, перечисления (Enums) и интерфейсы репозиториев.
*   `Hotel.Application` — бизнес-логика (сервисы), мапперы и DTO.
*   `Hotel.Infrastructure` — реализация `DbContext`, репозиториев и миграции EF Core.
*   `Hotel.WebAPI` — контроллеры и настройка DI.
*   `Hotel.MigrationService` — сервис для применения миграций при старте.
*   `Hotel.AppHost` — оркестратор Aspire.
*   `Hotel.Tests` — модульные тесты.

## REST API

Для каждой сущности реализованы операции получения списка, получения по идентификатору, создания, изменения и удаления (CRUD).

| Сущность | Маршрут |
|---|---|
| Клиенты | `/api/clients` |
| Типы номеров | `/api/roomtypes` |
| Номера | `/api/rooms` |
| Бронирования | `/api/bookings` |

## Аналитические запросы

Реализованы следующие аналитические маршруты:

1. `GET /api/analytics/clients-by-room-type/{category}` — получение списка клиентов, проживавших в номерах указанного типа, отсортированных по ФИО.
2. `GET /api/analytics/current-bookings` — получение информации о номерах, находящихся в текущем бронировании (на текущую дату).
3. `GET /api/analytics/top5-rooms` — получение топ-5 наиболее часто бронируемых номеров.
4. `GET /api/analytics/rooms-booking-count` — вывод числа бронирований для каждого номера.
5. `GET /api/analytics/top5-clients` — получение топ-5 клиентов по суммарной стоимости проживания.
