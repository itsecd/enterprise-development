# Разработка корпоративных приложений — лабораторная работа №1

## «Классы»
В рамках первой лабораторной работы реализована объектно-ориентированная модель салона красоты, подготовлены тестовые данные и unit-тесты с использованием LINQ. Данные хранятся в памяти в виде коллекций.

Вариант: 37

---

## Предметная область
Проект моделирует работу салона красоты.

### Основные сущности
| Класс | Назначение |
|---|---|
| `Client` | Клиент салона красоты |
| `Master` | Мастер салона красоты |
| `Service` | Услуга (справочник) |
| `Appointment` | Запись клиента на услугу к мастеру |

### Базовый класс
Так как `Client` и `Master` обладают значительным количеством общих свойств, выделен базовый абстрактный класс:
* `Person` — ФИО, пол, дата рождения (только для клиента), идентификатор.

### Перечисления
`Gender` — пол человека:

- `Male`
- `Female`

---

## Unit-тесты
* Мастера, стаж работы которых не менее 5 лет.
* Окошки (промежутки времени между записями) выбранного мастера.
* Топ-5 наиболее популярных услуг.
* Количество повторных записей клиентов за последний месяц.
* Клиенты, записанные к нескольким мастерам, упорядоченные по дате рождения.
