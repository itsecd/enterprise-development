# Лабораторная работа №3

## Предметная область

Служба доставки еды (вариант №9)

## Описание

В рамках лабораторной работы реализовано хранение данных серверного приложения с использованием Entity Framework Core и PostgreSQL.

Настроены миграции для создания структуры базы данных и её первоначального заполнения, а также оркестрация API и PostgreSQL с помощью .NET Aspire.

## База данных

База данных включает следующие таблицы:

- `Clients` — клиенты службы доставки
- `Restaurants` — рестораны
- `DishCategories` — категории блюд
