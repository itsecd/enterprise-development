## Описание

В рамках третьей лабораторной работы хранение данных было переведено с коллекций в оперативной памяти на полноценную объектно-реляционную базу данных. Также была настроена оркестрация приложения с помощью .NET Aspire.

### Основные изменения:
* **Domain:** Содержит доменные модели и классы-сиды.
* **Infrastructure:** Выделен отдельный проект для работы с данными. В нем реализованы паттерны Репозиторий (`IRepository`, `EfCore...Repository`), настроен `DbContext` и созданы миграции EF Core.
* **API:** Контроллеры переведены на использование интерфейсов репозиториев. Внедрены DTO (Data Transfer Objects) для изоляции доменных моделей от внешнего мира.
* **AppHost (.NET Aspire):** Выступает в роли оркестратора. Автоматически поднимает Docker-контейнер с MySQL, создает базу данных `cleaningdb`, передает строку подключения в API и запускает само API. Также предоставляет Aspire Dashboard для мониторинга логов и состояния сервисов.

### Хранение данных:
* Данные хранятся в СУБД **MySQL** (Docker-контейнере).
* Для управления схемой БД используется подход **Code First** (EF Core Migrations).
* Первичное заполнение (сидирование) таблиц тестовыми данными (10 категорий, 10 клиентов, 10 изделий, 15 заказов) происходит автоматически при применении миграций.

### CRUD-контроллеры и API:
Контроллеры поддерживают стандартные HTTP-методы (GET, POST, PUT, DELETE):
* `ClientsController` (`/api/clients`) — управление клиентами.
* `CategoriesController` (`/api/categories`) — управление категориями изделий.
* `ItemsController` (`/api/items`) — управление изделиями с валидацией существования категории.
* `OrdersController` (`/api/orders`) — управление заказами с валидацией существования клиента и изделия.

### Аналитический контроллер (`AnalyticsController`):
Предоставляет результаты запросов:
1. `GET /api/analytics/orders-in-progress` — заказы в обработке.
2. `GET /api/analytics/top-clients` — Топ-5 клиентов за период.
3. `GET /api/analytics/clients-with-longest-orders` — клиенты с максимальным сроком выполнения заказа.
4. `GET /api/analytics/categories-most-popular` — Топ-5 популярных категорий.
5. `GET /api/analytics/categories-least-popular` — Топ-5 непопулярных категорий.
6. `GET /api/analytics/top-spending-client` — клиент с наибольшей суммой затрат.

## Запуск

1. **Запуск всей системы через .NET Aspire:**
   проект **`DryCleaning.AppHost`** в качестве запускаемого:
   ```bash
   dotnet run --project DryCleaning/DryCleaning.AppHost/DryCleaning.AppHost.csproj
   ```

2. **Запуск модульных тестов:**
   ```bash
   dotnet test DryCleaning/DryCleaning.sln
   ```
