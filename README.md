# Лабораторная работа №2 — Сервер

## Цель работы

Разработать серверное веб-приложение на базе ASP.NET Core, реализующее базовые CRUD-операции для доменных сущностей предметной области «Фитнес-клуб», обеспечивающее валидацию бизнес-правил при бронировании и использующее хранение данных в оперативной памяти с проверкой аналитических выборок модульными тестами xUnit.

## Архитектура решения

Проект разделен на три слоя:

- `FitnesClub.Domain` — доменная модель (`Person`, `Member`, `Trainer`, `Booking`, `Specialization`, `Gender`) и инициализатор данных `DataSeeder`;
- `FitnesClub.Api` — веб-приложение ASP.NET Core:
  - DTO-контракты (`record`) и методы расширения для маппинга;
  - обобщенный интерфейс `IRepository<T, TId>` и репозитории хранения данных в оперативной памяти (`InMemory...Repo`);
  - REST-контроллеры для работы по протоколу HTTP;
- `FitnesClub.Tests` — модульные тесты xUnit v3 с тестовой фикстурой `FitnesFixtures`.

## Реализованный функционал

### 1. CRUD-операции

Реализованы REST-контроллеры для полного цикла управления данными (Create, Read, Update, Delete):

- `TrainersController` (`/api/trainers`) — управление данными тренеров;
- `MembersController` (`/api/members`) — управление данными клиентов;
- `SpecializationsController` (`/api/specializations`) — справочник направлений и специализаций;
- `BookingsController` (`/api/bookings`) — управление записями на персональные тренировки.

### 2. Бизнес-логика и валидация связей

В `BookingsController` реализована валидация целостности данных и ограничений предметной области:
- проверка существования клиента и тренера по переданным идентификаторам;
- проверка срока действия абонемента клиента (дата занятия должна попадать в диапазон действия абонемента);
- проверка занятости тренера для исключения наложения времени тренировок в расписании.

## Документация API

Для проверки и ручного тестирования эндпоинтов подключен Swagger UI (`/swagger`).

## Модульное тестирование

Для тестирования используется **xUnit v3** и тестовая фикстура `FitnesFixtures`, наполняемая из `DataSeeder`.

В классе `FitnesTests` реализованы тесты проверки аналитических запросов со сверкой с эталонными данными:

1. Фильтрация тренеров со стажем работы не менее 5 лет.
2. Проверка доступности зала для записи в текущий момент (свободен / занят).
3. Выборка клиентов с просроченным абонементом с сортировкой по ФИО.
4. Выборка занятий за текущий месяц в выбранном зале.
5. Расчет топ-5 наиболее популярных тренеров по количеству бронирований.
