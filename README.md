# Лабораторная работа №1

## Вариант 25 — Служба доставки еды"

**Предметная область:** служба доставки еды.

**База данных по варианту:** PostgreSQL.

**Брокер сообщений по варианту:** NATS.

**Платформа:** .NET 10.

**Тестирование:** xUnit v3.

## Цель работы

Реализация объектно-ориентированной модели данных предметной области и unit-тестов аналитических LINQ-запросов.

## Реализованные классы

- `Client` — клиент службы доставки: ФИО, телефон, адрес доставки;
- `DishCategory` — справочник категорий блюд;
- `Dish` — блюдо: название, вес, цена, категория, ресторан;
- `Restaurant` — ресторан: название, адрес, рейтинг, часы работы;
- `Order` — заказ: клиент, ресторан, время оформления, время доставки, итоговая сумма;
- `OrderItem` — позиция заказа: блюдо, количество и цена на момент заказа.

В `DataSeeder` подготовлено не менее 10 экземпляров каждого класса.

## Unit-тесты

1. Топ-5 ресторанов по количеству заказов.
2. Все заказы с минимальным временем доставки.
3. Все клиенты, заказывавшие в выбранном ресторане, с сортировкой по ФИО.
4. Сводная информация по каждой категории блюд за указанный период: количество заказов, средняя сумма заказа и общая сумма заказов.
5. Клиент, потративший на доставку наибольшую сумму за всё время работы приложения.
6. Проверка требования о наличии минимум 10 экземпляров каждого класса.

Для запроса №4 используется `OrderItem`, поскольку один заказ может содержать блюда разных категорий. Категория определяется через блюдо, после заказы группируются по категории.

## Запуск и проверка

Требуется установленный .NET SDK 10.

```bash
dotnet --version
dotnet restore
dotnet build
dotnet test
```

Для запуска только тестового проекта:

```bash
dotnet test tests/EnterpriseDevelopment.Domain.Tests/EnterpriseDevelopment.Domain.Tests.csproj
```

Для запуска тестов непосредственно как xUnit v3 executable:

```bash
dotnet run --project tests/EnterpriseDevelopment.Domain.Tests/EnterpriseDevelopment.Domain.Tests.csproj
```
