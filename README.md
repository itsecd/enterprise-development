## Реализация

Модель описывает рестораны, меню блюд, клиентов, курьеров и заказы службы доставки еды. Данные хранятся в коллекциях в памяти. Пять запросов из задания реализованы с помощью LINQ и проверяются модульными тестами xUnit.


| Тип | Назначение |
|---|---|
| `Restaurant` | Ресторан: название, адрес и перечень предлагаемых блюд |
| `Dish` | Блюдо из меню ресторана: наименование, стоимость и категория |
| `Customer` | Клиент службы доставки: контактные данные и адрес доставки |
| `Courier` | Курьер: персональные и контактные данные исполнителя заказа |
| `Order` | Заказ: состав блюд, клиент, курьер, время оформления, статус и способ оплаты |
| `DishCategory` | Категория блюда в меню |
| `OrderStatus` | Текущий статус выполнения и доставки заказа |
| `PaymentMethod` | Способ оплаты заказа |

Обязательные ссылочные свойства помечены модификатором `required`. Категории блюд, статусы заказов и способы оплаты представлены перечислениями (`Enums`). Публичные классы, свойства и перечисления снабжены XML-комментариями.
