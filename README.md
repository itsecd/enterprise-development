# Лабораторная работа №2

## Вариант 25 — служба доставки еды

Серверное приложение на .NET 10 предоставляет REST API для работы с сущностями из первой лабораторной работы и аналитическими запросами. Данные хранятся в памяти и при перезапуске восстанавливаются из `DataSeeder`.

## Запуск

Необходим .NET SDK 10.

```bash
dotnet restore
dotnet build
dotnet test
dotnet run --project src/FoodDelivery.Api --urls http://localhost:5000
```

## CRUD

Для каждой сущности доступны запросы `GET` (список), `GET /{id}`, `POST`, `PUT /{id}`, `DELETE /{id}`:

- `/api/clients` — клиенты;
- `/api/restaurants` — рестораны;
- `/api/categories` — категории блюд;
- `/api/dishes` — блюда;
- `/api/orders` — заказы;
- `/api/order-items` — позиции заказов.

Тела `POST` и `PUT` передаются в JSON. Идентификатор при создании назначается сервером; при изменении используется идентификатор из адреса. Связи задаются через идентификаторы: например, для блюда — `categoryId` и `restaurantId`, для заказа — `clientId` и `restaurantId`, для позиции — `orderId` и `dishId`. Удалить сущность, на которую есть ссылки, нельзя: сервер вернёт `409 Conflict`.

Пример создания клиента:

```bash
curl -X POST http://localhost:5000/api/clients -H "Content-Type: application/json" -d '{"fullName":"Иван Иванов","phoneNumber":"123","deliveryAddress":"ул. Лесная, 1"}'
```

## Аналитические запросы

- `GET /api/analytics/top-restaurants` — пять ресторанов с наибольшим количеством заказов;
- `GET /api/analytics/fastest-orders` — все заказы с минимальным временем доставки;
- `GET /api/analytics/restaurants/{id}/clients` — уникальные клиенты ресторана, отсортированные по ФИО;
- `GET /api/analytics/category-statistics?start=2026-02-01T00:00:00Z&end=2026-05-01T00:00:00Z` — количество, средняя и общая сумма заказов по категориям за период; начало включено, конец исключён;
- `GET /api/analytics/top-clients` — клиенты с максимальной суммой заказов, включая совпадения.

В статистике категорий заказ учитывается один раз для каждой категории, блюда которой он содержит. Сумма заказа учитывается целиком, как в запросе первой лабораторной работы.
