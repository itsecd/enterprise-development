# Лабораторная 3 — ORM

Салон красоты, вариант 80. Данные API хранятся в MS SQL Server. EF Core при первом запуске создаёт четыре таблицы и загружает 10 посетителей, 10 специалистов, 10 услуг и 35 записей.

## Запуск

Понадобятся .NET 10 и запущенный Docker с поддержкой Linux-контейнеров. В PowerShell из корня решения:

```powershell
dotnet dev-certs https --trust
dotnet run --project BeautySalon.AppHost
```

В панели Aspire видно контейнер `sql`, базу `salondb` и проект `api`. Строку подключения передаёт Aspire. API ждёт базу и применяет миграции перед запуском маршрутов. Данные контейнера сохраняются в томе Docker. Для просмотра OpenAPI открой адрес ресурса `api` и добавь `/scalar`.

В чистой базе по адресу `/api/analytics/specialists/2/free-windows?date=2026-11-22` доступны три окна. Для проверки записей за месяц используй `/api/analytics/repeat-appointments?asOf=2026-11-20T12:00:00`. Даты начальных записей зафиксированы в миграции, поэтому эти запросы можно повторить в любой день.

## Как устроено хранение

- `SalonDbContext` описывает таблицы, внешние ключи, точность цены и индекс уникальности паспорта
- SQL-репозитории выполняют выборки и CRUD асинхронно с токеном отмены HTTP-запроса
- При записи на услугу транзакция блокирует изменение расписания до завершения проверки и сохранения
- Свободные окна вычисляются между записями специалиста. SQL находит следующий старт и учитывает самое позднее окончание среди предыдущих записей
- Повторной считается запись, у которой есть предшествующая запись того же посетителя, в том числе до начала выбранного месяца

## Сборка и миграции

```powershell
dotnet build BeautySalon.slnx --configuration Release
dotnet test --configuration Release --no-build
dotnet tool restore
dotnet ef migrations list --no-connect --project BeautySalon.Infrastructure --startup-project BeautySalon.Infrastructure
```

Чтобы проверить API на уже работающем SQL Server без Aspire, задай переменную окружения `ConnectionStrings__salondb` со строкой подключения и запусти `dotnet run --project BeautySalon.Api`. На Windows для локальной проверки можно использовать SQL Server LocalDB.

Для воспроизведения примера закреплена версия Aspire 13.5.4 из ветки 13.5, указанной в задании. Панель Aspire предназначена для локального запуска.
